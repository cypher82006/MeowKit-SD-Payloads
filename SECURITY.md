# 🛡️ Security Policy & Payload Disclosure

## 🎯 Scope & Dual-Use Intent

The **MeowKit-SD-Payloads** repository contains offensive security modules, radio frequency tools, network diagnostic apps, and keystroke injection scripts designed for the **MEOWKit ESP32-S3 Handheld Cyber Multitool**.

### ⚠️ Ethical Hacking Disclaimer
* **Authorized Auditing Only:** All scripts, binaries, and payloads in this repository are developed strictly for authorized penetration testing, security research, hardware auditing, and educational demonstrations on equipment you own or have explicit written permission to test.
* **No Destructive Payloads:** This repository strictly prohibits the creation, submission, or hosting of untargeted malware, ransomware, destructive wipers, or self-propagating worms.
* **Liability:** The authors and maintainers assume no liability for misuse, unauthorized access, or regulatory infractions caused by the deployment of these payloads.

---

## 🔍 Reporting a Vulnerability or Unsafe Payload

If you discover a payload that escapes memory bounds, causes unrecoverable device bricking, or violates our non-destructive research standard:

### Preferred Method: GitHub Private Vulnerability Reporting
1. Navigate to the **Security** tab of this repository.
2. Select **Advisories** -> **Report a vulnerability**.
3. Specify the affected payload, the vulnerability details, and reproduction steps.

### Alternative Method: Direct Encrypted Email
* Send disclosure details to **security@darkcyfr.xyz**.
* Maintainers will acknowledge reports within **48 hours** and coordinate remediation within a standard **90-day disclosure timeline**.
